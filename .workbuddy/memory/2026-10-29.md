## 通读 javSpy 代码（首次全局理解）

- 项目定位：单体 Spring Boot 2.6.13 / Java 11 + Vue3(Vite, Element Plus) 的 javbus 刮削与影片库工具。
- 后端入口 `JavspyApplication`；核心包 `org.holic.javspy.javbusapi`（client / controller / service / mapper / model）与 `org.holic.javspy.misc`（Emby、图片下载、通用返回）。
- 关键链路：Controller → `JavbusApiService` → `JavbusApiClient`(OkHttp, 全局 300ms 限速, 可走 SOCKS5) → `JavbusApiSaveService.persist`(@Transactional 单事务, 实体表→影片→封面→磁力→关联表)。
- 设计要点：`JavbusApiSaveService` 单独拆 Bean 是为了让事务代理生效（避免同类自调用 @Transactional 失效）；列表页用 count 短时缓存 + PageHelper(count=false)；展示信息用 `findDisplayExtras` 一条 SQL 聚合，避免 N+1。
- Emby 存在性：`emby_movie` 表做每日全量覆盖缓存 + 进程内当日缓存。
- 图片：下载到 `conf.image.storage-path`，`WebPicConfig` 映射 `/pic/**`。
- 前端：hash 路由 4 个页面（影片库/最新入库/演员搜索/刮削中心），构建产物手放到 `src/main/resources/static/`，随 jar 发布。
- 已知待改（下次可接手）：persist 事务内含 HTTP 封面下载（长事务）；`getStrBeforeSpace` 取番号易产生脏数据；Emby 全量拉取未分页；`getImageUrl` 异常分支混乱且不校验残缺文件；两个单线程池无 shutdown；配置明文密码/API Key。
